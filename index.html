De la ecuación de 2º grado a la bicuadrada

Ya sabes calcular el discriminante y usar la fórmula. Aquí damos el paso siguiente: reconocer qué tipo de ecuación tienes, resolverla con la técnica más cómoda y descubrir que una bicuadrada es una ecuación de 2º grado disfrazada.

Antes de nada, siempre: ordena e iguala a 0. Hasta que no esté en la forma ax^2 + bx + c = 0 (o ax^4 + bx^2 + c = 0) no se sabe de qué tipo es.

Ejemplo: 2x^2 + x - 3 = 0

\Delta = 1^2 - 4\cdot 2\cdot(-3) = 1 + 24 = 25 \qquad x = \dfrac{-1 \pm 5}{4} \;\left\{\begin{array}{l} x_1 = \dfrac{4}{4} = 1 \\[8pt] x_2 = \dfrac{-6}{4} = -\dfrac{3}{2} \end{array}\right.
Ojo con los signos: si b = -5, entonces b^2 = (-5)^2 = 25 (positivo) y -b = 5.

Incompletas: sin fórmula

Falta el número: factor común

3x^2 - 12x = 0 \;\Rightarrow\; 3x\,(x - 4) = 0 \;\left\{\begin{array}{l} 3x = 0 \;\rightarrow\; x = 0 \\[6pt] x - 4 = 0 \;\rightarrow\; x = 4 \end{array}\right.

Un producto vale 0 si alguno de sus factores vale 0. Por eso x = 0 siempre es solución.

Falta el término en x: despejar

2x^2 - 18 = 0 \;\Rightarrow\; 2x^2 = 18 \;\Rightarrow\; x^2 = 9 \;\Rightarrow\; x = \pm\sqrt{9} = \pm 3
3x^2 + 12 = 0 \;\Rightarrow\; x^2 = -4 \;\Rightarrow\; \text{no tiene solución real}
Al hacer la raíz, siempre las dos: + y -. Y si x^2 es negativo, no hay solución.

El puente: una bicuadrada es una de 2º grado disfrazada

Mira las dos ecuaciones. Las cuentas son exactamente las mismas; en la bicuadrada, x^2 hace el papel de z.

Ecuación de 2º grado
z^2 - 5z + 4 = 0
z = \dfrac{5 \pm \sqrt{25 - 16}}{2} = \dfrac{5 \pm 3}{2}
z = 4 \qquad z = 1

2 soluciones.

Bicuadrada
x^4 - 5x^2 + 4 = 0 \;\xrightarrow{\;x^2 = z\;}\; z^2 - 5z + 4 = 0
z = 4 \qquad z = 1
x^2 = 4 \rightarrow x = \pm 2 \qquad x^2 = 1 \rightarrow x = \pm 1

4 soluciones: el único paso nuevo es deshacer el cambio.

¿Cuántas soluciones puede haber?

Una de 2º grado, como mucho 2: lo decide \Delta. Una bicuadrada, como mucho 4: \Delta dice cuántas z hay, y después el signo de cada z dice cuántas x salen.

    ¿Cómo escribo las soluciones?
